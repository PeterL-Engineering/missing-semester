### 3. Removing a file from history

One common mistake when learning Git is to commit large files
that should not be managed by Git or adding sensitive
information. Try adding a file to a repository, making some
commits and then deleting that file from history (not just the
latest commit). You may want to look at this.

### 5. Git aliases

Like many command line tools, Git provides a configuration
file (or dotfile) called `~/.gitconfig`. Create an alias in
`~/.gitconfig` so that when you run `git graph`, you get the
output of `git log --all --graph --decorate --oneline`. You
can do this by directly editing the `~/.gitconfig` file, or
you can use the `git config` command to add the alias.
Information about git aliases can be found here.
