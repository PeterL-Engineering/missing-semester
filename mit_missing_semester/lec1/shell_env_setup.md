## 0 Overview

This document provides a list of useful add-ons and tips for setting up and using a Shell environment.

## 1 List of Helpful Add-ons
- Consider installing and using `tldr` in addition to `man`, 
as it shows you common usage examples right there in the terminal. 
LLMs are also usually very good at explaining how commands work and 
how you can call them to achieve what you want to accomplish.
- Consider installing and using `zoxide` to speed up your `cd`ing — 
`z` will remember the paths you frequently visit and let you access 
with less typing
- Consider installing and using `eza` for a more human-friendly `ls`
- Consider installing and using `bat` over `cat` for syntax 
highlighting and scrolling.
- Consider installing and using `ripgrep` over `grep` for a faster 
and more human-friendly (but less portable) alternative. 
`ripgrep` will also recursively search the current working directory 
by default!
